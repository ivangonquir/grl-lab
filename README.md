# Graph Representation Learning Lab

Repository for the **Graph Representation Learning** laboratory assignment on **Knowledge Graph Embeddings (KGEs)** and **Graph Neural Networks (GNNs)**.

---

## Assignment Overview

This project is divided into two parts.

### Part A — Knowledge Graph Embeddings (KGEs)

The first part explores representation learning on a citation knowledge graph derived from the PubMed dataset. The experiments include:

- Construction of a citation knowledge graph.
- Training a basic TransE model.
- Analysis of embedding geometry and retrieval capabilities.
- Hyperparameter tuning of best performing model.
- Comparison of multiple KGE models, including:
  - TransE
  - TransH
  - DistMult
  - ComplEx
- Analysis of negative sampling strategies and their impact on performance.

### Part B — Graph Neural Networks (GNNs)

The second part focuses on node classification using graph neural networks. The experiments include:

- Classification using node features only.
- Exploiting graph structure through message passing.
- Analysis of network depth and oversmoothing.
- Mutual-information experiments.
- Extraction and visualisation of learned node embeddings.

The outputs generated by the experiments, including trained models, embeddings, evaluation results, and figures, are stored in the repository and referenced throughout the accompanying report.

## Environment Setup

Clone the repository:

```bash
git clone https://github.com/ivangonquir/grl-lab.git
cd grl-lab
```

### Linux / macOS

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

### Windows (PowerShell)

Create and activate a virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```
